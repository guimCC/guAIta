# 0001 - MVP Scope

## Decision

Build a controlled 3-minute operational demo, not a complete GIS or IoT platform.

## Context

The team has 36 hours. The strongest demo value comes from showing a working edge detection path, a polished dashboard, deterministic scenario control, and useful recommendations.

## Implications

- Preconfigure stations, zones, and scenarios.
- Do not implement full zone drawing in MVP.
- Do not implement full station management in MVP.
- Keep the first scenario deterministic and rehearseable.
- Make the dashboard feel real through map visuals, alerts, metrics, and action recommendations.
